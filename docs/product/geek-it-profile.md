# 极客 IT 个人站首版需求

## 产品定位

首版产品是一个面向个人展示和后续迭代的极客 IT 男生个人站，同时提供 Web 和移动 App 两个入口。它不是博客系统、不是 SaaS 后台，也不在首版引入登录、内容管理或复杂数据库读写。

核心目标：

- 明天可以在线访问一个视觉完成度较高的 Web 首屏和完整落地页。
- 移动 App 有对应的信息架构和可体验的首页。
- 所有自拟展示内容集中记录，后续可以替换成真实个人资料。
- 部署链路使用 GitHub Actions 构建镜像并部署到单机 Docker 服务器。

## 首版用户画像

访问者可能是朋友、合作方、招聘方或未来产品用户。他们希望快速判断：

- 这个人擅长什么技术方向。
- 最近在做什么项目。
- 工程习惯是否可靠。
- 是否可以联系、合作或继续关注。

## 首版信息架构

### Web

Web 作为主要体验入口，包含以下区块：

- Hero：一句清晰定位、短介绍、关键行动按钮、在线状态。
- Signal board：展示工作节奏、技术偏好和当前服务状态。
- Stack：展示前端、后端、移动端、基础设施能力。
- Projects：展示 3 个可继续迭代的项目卡片。
- Journal：展示近期构建日志和思考条目。
- Contact：提供合作入口和异步联系偏好。

### Mobile App

移动 App 作为随身名片和状态面板，包含以下区块：

- 顶部身份定位。
- 服务健康状态。
- 技术栈摘要。
- 项目摘要。
- 联系提示。

移动 App 不复刻 Web 的完整视觉结构，保持 React Native 自己的布局和交互。

## 内容归属

展示内容属于共享业务内容，存放在 `packages/domain/src/profile.ts`。Web 和 App 都从 `@app/domain` 读取，避免两端复制文案。

UI 只负责展示和轻量交互，不在组件内散落核心展示数据。

## 设计方向

- 风格：克制、清晰、偏工程师工作台，不做营销页浮夸视觉。
- 色彩：深色基底、青绿色信号色、少量暖色强调，避免单一紫蓝渐变。
- 字体：系统无衬线，强调可读性。
- 交互：轻量动效，按钮和状态卡在移动端可触控。
- 视觉资产：Web 首屏使用生成的真实工作台位图 `apps/web/src/assets/geek-workstation-hero.png`。

## 首版验收标准

- `pnpm typecheck` 通过。
- `pnpm build` 通过。
- Web 首屏不依赖 `localhost` API，生产默认通过 `/api` 同源访问。
- App 可以在本地 Expo 环境编译类型检查。
- GitHub Actions 部署所需的 Secrets 和 Variables 有明确清单。
- 服务器可以通过 SSH 访问并具备 Docker 与 Docker Compose。
- 上线后 `http://43.110.116.98/health` 返回 API 健康状态。

## 暂不做

- 用户登录和权限系统。
- 后台 CMS。
- 真实博客详情页。
- 数据库存储个人资料。
- App 商店打包发布。
